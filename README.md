# CalCOOLator 2.5

Cute and functional web calculator!

This is basically the prettier and slightly less cursed version of my first calculator project.

## Features

- Addition
- Subtraction
- Multiplication
- Division
- Decimals
- Percentages
- Positive/negative numbers
- Chained operations
- Repeated `=` operations
- Division by zero protection

## Built with

- HTML
- CSS
- JavaScript
